# しんたろうジャンケン2

既存のオープンマッチ（5人）、CPU戦（自分＋CPU4人）、プライベートマッチ（2〜10人）を搭載した Socket.IO ゲームです。

## 起動
Node.js 20以上で `npm install` → `npm start`、ブラウザで `http://localhost:3000`。

## ルール
- グー負け0、チョキ負け2、パー負け5
- パー勝利時、パー勝者は各自グーの相手を1人指名して5点。重複指名の点数は合算
- フォー独占で他全員+2、フォー被りでフォーを出した全員+4
- フォーがない3連続あいこは全員+10
- 誰かが累計13点以上でマッチ終了。最高点が最下位
- プライベートルーム作成時にフォーあり／なしを設定可能

## CPU
堅太郎（グー・チョキ中心）、攻太郎（パー中心）、四太郎（フォー中心）、乱太郎（4手均等）、普太郎（従来CPUの確率）。
CPU4人戦では原則異なる4タイプを選出。プライベートでCPUを5人以上加えるとタイプの重複あり。
フォーなし設定時は、フォー確率を0にして他の手の重みで抽選。
CPUのパー指名はグーの人からランダム選択。

## デプロイ
GitHubにファイルをアップロードし、RenderのNode Web Serviceに接続。
Build: `npm install` / Start: `npm start`。
既存サイトと別のURLにしたい場合は新しいRenderサービスを作成してください。

## 注意
試作版。ルームとスコアはメモリ保存のためサーバー再起動で消えます。再接続で試合に復帰する仕組みは未実装。CPU戦もサーバー接続が必要です。パー指名時はグーのプレイヤー名を指名者に表示します。
